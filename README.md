# Task:15 JavaScript Array Operations & Functions

## Objective
The objective of this assignment is to create JavaScript functions that accept an array as an argument and perform different operations on the array.

## Tasks
The program performs the following operations:

- Find the maximum number in the array.
- Calculate the sum of all elements in the array.
- Count the number of odd numbers in the array.
- Display the results using `console.log()`.
